# quye.com

中文 AI 编程中心。构建期从四门中文编程语言仓库（极快 / 段言 / 光明 / 知行）抽取核心源码，
打包进浏览器端 Pyodide 沙箱，用户在网页里「中文需求 → 组码 → 当场运行」，无需后端。

纯 Python 标准库构建 + 原生前端（无框架、无打包工具）。

## 站点功能（M3 交付后）

- **首页** `/` — 四门语言入口卡片
- **语言** `/语言/` — 四门语言介绍索引 + 各语言详情页
- **工作台** `/台/` — 选语言 → 输入需求 → AI 选块 → 组码 → 浏览器跑
- **对照** `/对照/` — 同一需求四门语言并排跑
- **学习** `/学/` — 19 关卡（段言 10 + 光明 9），浏览器内判对，进度 localStorage
- **本地开发** `/本地/` — 四门语言安装 / CLI / IDE 配置
- **文档** `/文档/` — 12 篇精选 md（上手/语言特色/工具链/安全）
- **路线图** `/路线图/` — 三阶段愿景

## 构建

需要 Python 3.10+ 和 git。

```powershell
python 建站.py
```

构建流程：取版本 → 生成各页面（首页/语言/路线图/本地/工作台/对照） → 复制静态资源 → 抽取四门语言包（+ zip 打包） → 抽取学习素材 → 复制示例集 → **预跑门禁**（示例 + 学习基线 19/19） → 构建学习区 → 抽取并构建文档区 → 自托管 Pyodide。

门禁工具（可独立复跑）：
```powershell
python 工具/命中率实测.py   # 30 条需求，< 60% 退出码 1
python 工具/产物自检.py     # 站内死链 + 关键路由 + 学习区页数
```

## 本地预览

```powershell
python -m http.server 8080 --directory 出
```

然后浏览器打开 `http://localhost:8080/`：

- 选「极快」→ 输需求 → 选块 → 组码 → 跑
- 选「段言/光明/知行」→ 直接写代码 → 跑

### 学习 `/学/`

- 4 列并排，切示例同步刷新，各格独立跑

## 部署

`出/` 目录由 GitHub Actions 部署到 GitHub Pages，绑定 `ai.quye.com`（见 `源/CNAME`）。
双远端：`origin`（GitHub）+ `gitcode`（GitCode）。

```powershell
git push origin main
git push gitcode main
```

## 技术要点

- **语言包 zip 打包**：构建期把每门语言的 `.py/.jk/.json` 打成单个 zip，Worker 用 `py.unpackArchive()` 一次解包；逐文件 fetch 保留作兜底。
- **极快选块走启发式 TF-IDF**（63KB 索引，纯标准库，无 GPU）。命中率 83%（30 条真实需求，top-5）。
- **学习基线构建期生成**：跑每关参考答案抓 stdout 作判对基准，既做判对又做跨语言回归门禁。
- **讨论区按语言切换**：页脚讨论区组件根据 `data-讨论语言` 自动指向对应仓库的 issues/discussions。
- **站内死链门禁**：`工具/产物自检.py` 全量扫描 html 里的 `href`/`src`，映射到产物文件系统，任一 404 即报错。

## 已知限制

- **极快向量检索未启用**：浏览器无嵌入模型，检索仍走 TF-IDF。83% 命中率下无需兜底入口。
- **`台.js` 的 `_示例值表` 待删除**：依赖 jikuai 落地 `synthesize` 复用块示例后才能清理。
- **组码骨架带 `?` 占位符**：极快 `synthesize` 只搭结构，多参块需手动填参。
- `取版本()` 偶尔报「双端不同步」，只是提示，不阻断构建。
