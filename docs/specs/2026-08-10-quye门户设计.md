## 1. 定位与产品主张

**一句话定位**

> quye.com 是一个**中文 AI 编程中心**：用中文说话，让代码自己长出来，在浏览器里当场跑。

**北极星**

用户用中文描述需求 → AI 组出中文代码 → 当场跑出结果。所有功能只要问一句"这个能让北极星更亮吗"，答不上就砍。

**四条支柱主张**（按优先级）

1. **AI 而不依赖大模型** —— 依托极快的启发式检索（63KB 索引 + 纯标准库 TF-IDF），无需 API Key、无需 GPU、无需联网调外部服务就能"需求 → 代码 → 运行"。这是全站唯一的、别人抄不了的差异化主张，主打"极低资源 AI 编程"。
2. **零后端零安装** —— Pyodide 把四门语言的解释器全放到浏览器里，quye.com 本身托管在纯静态 CDN 上，用户零安装。
3. **中文编程语言家族对照** —— 同一个需求横向看极快、段言、光明、知行四门语言各自的写法，每门语言的独特哲学一目了然。
4. **通往分布式 AI 编程语言的路径** —— 远期北极星。首版通过路线图页把这个愿景清晰展示出来，但不做承诺的实现。

**明确不做（YAGNI）**

- 用户账号系统、自建社区/论坛/评论（首版全站零后端）
- 服务器端执行沙箱、LLVM 原生编译在线体验
- 大模型 API 代理（如果二期真要接大模型，一定是 BYOK 前端直连）
- 支付、订阅、增值服务
- 搜索框（首版内容量不值得）

### 2.4 讨论区双入口（组件）

不建独立 `/社区` 页，作为一个组件放在门户底部、各语言页、文档页页脚。

```
讨论与反馈
┌────────────────────┐ ┌──────────────────┐
│ GitCode 讨论区  ★  │ │ GitHub Discussions│
│ 国内访问快          │ │ 面向海外贡献者    │
└────────────────────┘ └──────────────────┘
       ↑ 默认高亮（★）
```

判定逻辑（纯客户端）：

```js
const 偏国内 =
  navigator.languages?.some(l => /^zh(-CN|-Hans)?$/i.test(l)) ||
  /^Asia\/(Shanghai|Chongqing|Urumqi|Harbin)$/.test(
    Intl.DateTimeFormat().resolvedOptions().timeZone
  );
```

三条纪律：**永不自动跳转**（只影响默认高亮）；**不用 IP 定位**（避免调外部服务泄露访客 IP）；**用户手动选择永远覆盖自动判定**，存 `localStorage`。

四门语言仓库全部 GitCode/GitHub 双端同步（极快 v0.15 W24 已固化"推双远端"），此组件无额外维护成本。

## 3. 技术架构

### 3.1 构建工具链：Python 脚本 + 原生前端

**决策理由**

- 用户机器上未装 Node，为一个六页静态站引入整条 npm 工具链不成比例。
- 四门语言全是 Python，构建脚本可直接 `import` 各语言的解释器预跑示例。
- 极快的 `tools/web/` 已经证明"手写 HTML/CSS/JS，几十行关键字染色，<15KB gzip"这条路走得通，可复用而非重写。
- 与四门语言"核心零运行时依赖"的纪律一致。

**目录结构**

```
quye/
├── 建站.py                    # 唯一构建入口，纯 Python 标准库
├── 模板/                      # 手写 HTML 模板（字符串替换）
├── 源/                        # 页面内容（markdown + HTML 片段）
├── 静态/
│   ├── 样式.css               # 手写，无 Tailwind
│   ├── 台.js                  # 工作台逻辑（原生 fetch + Pyodide）
│   ├── 执行器.js              # Web Worker：跑 Pyodide
│   └── py/                    # 构建期从四个仓库抽取的语言包
│       ├── 极快/  段言/  光明/  知行/
├── 数据/
│   ├── 示例结果.json          # 构建期预跑的官方示例结果
│   └── 极快索引.json          # 63KB，选块检索用
└── 出/                        # 构建产物，部署这个目录
```

### 3.2 Pyodide 四层懒加载

| 时机 | 加载什么 | 体积 |
|---|---|---|
| 门户首页 | 什么都不加载 | ~30KB |
| 进 `/台` `/对照` `/学` | 仍不加载，显示预计算结果 | +索引 63KB |
| 用户改代码 / 点"跑" | 拉 Pyodide runtime | ~6–10MB |
| 切到某门语言 | 拉那门语言的 py 包 | 每门 200–600KB |

Pyodide 从 CDN 拉，自托管一份兜底（国内访问 jsdelivr 不稳，实测风险，两条并发谁先到用谁）。

进 `/台` 立即在后台预热 Pyodide（用户看候选卡片的这几秒把 runtime 拉下来），减少首次点"跑"的可见等待。

### 3.3 执行环境：Web Worker + 5 秒超时

Worker 是必须的，**不是为了性能，是为了能杀掉死循环**。

- 主线程设 5 秒超时，超时 `worker.terminate()`
- 捕获 stdout/stderr 单独回传
- 每次执行用干净的 Worker，命名空间不残留上次的变量
- 触发死循环时 5 秒内被强制中止且页面不崩

### 3.4 四门语言打包策略

构建期从各仓库抽取，只抽核心链路，主动裁掉浏览器碰不到的东西：

**极快** —— `G:\traework\jikuai`
- 抽：`src/jikuai/`（排除 `pkg/sources.py` 的 git clone 路径）+ `stdlib/` + `tools/ai-bridge/glue.py` + `索引.json`
- 启发式检索路径原样可用
- 神经路径 `embed_client.py` 调 subprocess 会失败并自动降级到启发式（`ai/retrieval.py` 设计上已容错），不改

**段言** —— `C:\dumatework\duan`
- 抽：`src/duan_parser_v3.py` + `src/code_generator.py` + 依赖的 `ast_nodes*.py` `parser_*.py`
- **不导入** `src/compiler.py`（顶层 `import threading`）
- 调用链：`DuanParser().parse()` → `PythonCodeGenerator().generate()` → `exec()`

**光明** —— `gitcode.com/skywalk163/light`
- 抽：`src/`（lexer / light_parser_v3 / code_generator / parser_* / ast_nodes*）+ `stdlib/`
- 裁掉 `stdlib/网络.py` `stdlib/进程.py` `stdlib/线程.py`
- **不导入** `cli/light.py`（顶层 `import subprocess`）
- 调用链：`LightParser().parse()` → `PythonCodeGenerator().generate()` → `exec()`

**知行** —— `g:\zhixing`
- 抽：`src/zhixing/`
- 需改 `stdlib/loader.py` 的 `DEFAULT_LIBS`：给 loader 加 try/except 跳过加载失败的模块，剔掉 `c_lib`（ctypes）、`net_lib`（urllib）、`db_lib`（sqlite3）
- **这是四门语言里唯一需要真改一行源码的地方**。改成 try/except 容错对知行本身也是健壮性提升，不是为网站打的补丁

### 3.5 混合执行：预计算 + 按需唤醒

```
构建期（作者机器上，用真实解释器）
  ↓ 跑完所有官方示例、所有练习答案
  数据/示例结果.json  ← {示例ID: {源码, stdout, 返回值, 耗时}}
  ↓
浏览器（用户）
  打开页面      → 直接渲染缓存结果，0 延迟，不加载 Pyodide
  用户改了代码  → 唤醒 Pyodide + Worker，真跑
```

副产品：构建期预跑相当于给四门语言加了一层跨语言回归测试。任一门语言改坏了官方示例的行为，quye.com 构建立刻失败。

### 3.6 安全边界

**服务端零风险**：全站静态，无任何服务器执行用户代码的路径。

**分享代码链接的风险**（若二期实现 `/台?码=<base64>`）：
- URL 携带的代码**永不自动执行**，只填入编辑框
- 页面明确标注"来自分享链接，请先看一眼再运行"
- Worker 超时 5 秒硬中止兜底

**`/本地` 页显著标注**：极快的 pybridge 不是沙箱（`docs/安全边界.md` 与 ADR-21 明确声明，`DENY_LIST` 只是黑名单，`importlib` 可绕过）。诚实标注比藏起来对项目声誉更有利。

### 3.7 部署与语言版本策略

```
本地 python 建站.py → 出/
   ↓
推双远端（GitCode + GitHub）
   ↓
两边 CI 各自构建 → 各自 Pages
   ↓
quye.com  CNAME → 国内那份（GitCode Pages 或对象存储+CDN）
```

**四门语言跟 main 自动同步**（用户决策）。

原因：四门语言仍在快速迭代，固定 commit 会让 quye 频繁需要手动 bump。

代价与心智负担：某天某门语言合入破坏性改动，quye 构建会挂——这是设计好的行为，构建门禁替作者在合入 quye 之前就发现问题。回退方案：那次构建临时把出问题的语言 pin 到上一个好的 commit，同时去修那门语言。

每次构建把四门语言的 commit hash 记进 `版本.json` 并显示在页脚。用户看到的代码跑在哪个版本上，可追溯。

## 4. MVP 里程碑与验收

### 4.1 M1 · 门户可看（v0.1）

**范围**
- `/` 门户首页 + 四门语言卡片 + 双讨论区组件
- `/语言/<名>` 四门语言介绍页（各仓库 README 中文段抽取）
- `/路线图` 愿景页
- 零 JS 交互，秒开
- 域名接上

**验收标准**
- 生产环境 quye.com 可访问
- 首页 Lighthouse 性能分 ≥ 95
- 中英浏览器分别测双讨论区推荐正确
- 页脚显示当前四门语言的 commit hash + 构建时间

### 4.2 M2 · 工作台可跑（v0.2 · 北极星达成）

**范围**
- `/台` 工作台：三段式（需求 → 候选块 → 代码+结果）
- Pyodide 懒加载 + Web Worker + 5 秒超时
- 极快启发式选块跑通，`glue.synthesize` 组码跑通
- 四门语言各自能跑"打印/算术/条件"最简代码
- `/对照` 页四门语言并排跑同一需求
- 段言/光明/知行走"直接跑代码"路径，暂不接极快选块-组码

**验收标准**
- Chrome / Firefox / Edge 三家都能跑通端到端
- 官方示例集（见 4.8 定义）每个都能在预计算模式下秒开、在真跑模式下 3 秒内出结果
- 死循环 5 秒内被强制中止且页面不崩
- **首屏预算**：门户首页首字节到可交互 < 50KB（HTML+CSS+JS，不含图片）
- **工作台预算**：进入 `/台` 到显示预计算结果 < 150KB（含极快索引 63KB），此时 Pyodide 与语言包均未加载
- Pyodide runtime（约 6–10MB）与各语言包（每门 200–600KB）均为按需加载，不计入上述两项预算

### 4.3 M3 · 学习闭环（v0.3）

**范围**
- `/学/段言/*` 段言 tutorial 十套练习
- `/学/光明/*` 光明 L1_baihua 前 9 课
- 每关判对（跑出 stdout 与预期比对）+ 进度存 `localStorage`
- `/本地` 页四门语言本地安装与 IDE 配置指南
- `/文档/*` 精选 markdown（各仓库最关键 3-5 篇）

**验收标准**
- 至少 19 个练习关卡（10 段言 + 9 光明），每关都能判对
- 换浏览器后 localStorage 进度还能读回来
- 关键文档静态渲染无死链

### 4.4 构建脚本必须内置的门禁

每个里程碑通用，非"上线后再补"：

1. **示例回归**：官方示例集（见 4.8）构建期预跑一遍，任何一个挂掉构建失败
2. **链接检查**：所有内链、外链、文档链接构建期访问一遍
3. **仓库同步检查**：四门语言 GitCode 和 GitHub HEAD 是否一致，不一致告警
4. **Pyodide 冒烟**（M2 起）：构建产物起本地 http-server，用无头浏览器跑一次"点开工作台 → 跑 hello → 看结果"


### 4.5 首版风险与应对

**风险 A · Pyodide 冷启动 6-10MB**
- 应对：进 `/台` 立刻在后台预热 Pyodide；CDN + 自托管兜底并发

**风险 B · 极快选块检索质量决定第一印象**
- 应对：M2 上线前跑 30 条真实需求测命中率，低于 60% 加兜底路径"检索不到？直接写代码"

**风险 C · 跟 main 自动同步会打架**
- 应对：构建门禁在合入 quye 之前发现问题；回退方案是临时 pin 出问题的语言到上一个好的 commit

### 4.6 二期预留的钩子（不重构）

- **BYOK 大模型接入**：候选卡片区已预留"来源：启发式 / 神经 / 大模型"标签位
- **分享代码链接**：URL `?码=<base64>` 填入编辑框（不自动跑）
- **块生态第三方注册**：极快 W22 ADR-27 已在语言侧规范，二期做块广场页
- **VS Code 扩展下载页**：极快 W16 会打 `.vsix`，二期挂下载按钮

### 4.7 成功度量

只挑指向北极星的：

- **完成率**：进入 `/台` 的用户中，完成一次"需求 → 出代码 → 看到结果"完整流程的比例
- **多语言好奇度**：`/对照` 页到达率与人均查看语言数
- **学习留存**：`/学` 至少完成 3 关的用户占比
- **构建健康度**：CI 绿率、示例回归失败次数、跟 main 导致的失败次数

不追总 PV、不追 SEO 排名——那是营销站的度量，quye 是产品站。

### 4.8 「官方示例集」定义

门禁与验收标准反复引用这个概念，此处一次性定死。**官方示例集**是构建期预跑、结果写入 `数据/示例结果.json`、并在页面上展示的示例清单。首版收录：

- **极快**（6 条）：`examples/pipelines/01_多级过滤映射聚合.jk` 至 `06_中国特色管道.jk`
- **极快场景**（3 条）：`examples/scenarios/财务计算.jk`、`农历工具.jk`、`管道数据清洗.jk`
- **段言**（1 条 + M3 十套练习）：`examples/` 中一条最简示例；M3 起追加 `tools/tutorial/exercises/` 十套练习的参考答案
- **光明**（5 条 + M3 九课）：`examples/hello.light`、`basic.light`、`calculator.light`、`hanoi.light`、`playground/demos/fibonacci.light`；M3 起追加 `examples/L1_baihua/01_打印.light` 至 `09_异常.light`
- **知行**（1 条）：README 中的基础运算/递归示例

明确排除（依赖浏览器不可用的能力）：光明 `examples/L1_baihua/10_引Python画笑脸.light`（matplotlib）、任何走 LLVM 后端 / ANTLR 后端 / 包管理 / C FFI / 网络 / 文件 IO 的示例。

M2 验收要求：上述示例集中至少 16 条（极快 9 + 段言 1 + 光明 5 + 知行 1）全部通过。M3 验收要求：追加的 19 个练习关卡全部通过。
