# quye.com 项目总结与下季度规划

## 一、项目概览

**quye.com** 是四门中文编程语言（极快 / 段言 / 光明 / 知行）的统一门户网站，定位「零安装、浏览器里就能写中文代码」。

- 仓库：`github.com/skywalk163/quye` / `gitcode.com/skywalk163/quye`
- 技术栈：Python 3.10+ 标准库（构建期）、原生 JS + Web Worker + Pyodide 0.26.4（运行时）
- 构建脚本：`建站.py`（纯标准库，零第三方依赖）
- 产物：纯静态站，`python -m http.server 8080 --directory 出` 本地预览

## 四、下季度规划（2026 Q4：9 月 – 11 月）

### M4：CI 自动化 + 上游锁定（9 月上旬）

**目标**：让 quye.com 的构建在上游任一语言破坏兼容性时**自动暴露**（现在需要手动跑 `python 建站.py`），并能在不回退上游的情况下快速恢复站点。

- GitHub Actions workflow：push 或每日定时 → `python 建站.py` + `python 工具/产物自检.py` + `python 工具/命中率实测.py` → 全绿自动部署到 Pages；红牌时保留旧站不覆盖
- 四门语言版本锁：`建站.py` 浅克隆时记录 commit hash 到 `版本.json`，构建产物里标明依赖的上游快照
- 上游更新 PR bot：每日检查四门语言远端 HEAD 是否变化，变了开 issue 并尝试构建，通过则自动合入

### M5：用户增长 + 内容扩展（9 月下旬 – 10 月）

**目标**：让门户站从「能用」到「有人用」——补齐搜索引擎可发现性、社交分享、学习区内容密度。

- SEO 基础：每页 `<meta description>`、`sitemap.xml`、`robots.txt`、Open Graph 标签
- 学习区扩展：
  - 极快关卡（覆盖块生态入门 + 管道范式，约 8 关）
  - 知行关卡（覆盖管道 + 宏 + 同像性，约 6 关）
  - 光明 L2 文言体关卡（若规范稳定）
- 首页「每日一题」组件：从 19+ 关卡中随机一道，降低首次使用门槛
- 学习区进度导出/导入（JSON 下载/上传），解决换设备问题
- 文档区搜索（纯前端 lunr/minisearch，构建期生成索引）

### M6：工作台增强 + 块生态门户化（10 月 – 11 月）

**目标**：工作台从「选块组码」进化到「块生态浏览器」——让用户能发现、试用、对比极快的块，并为第三方块提供门户入口。

- 块浏览器 `/块`：按分类（财务/数据/日期/字符串/验证）列出所有块，每块可点进看签名、描述、在线跑示例
- 选块增强：候选区显示块简介 + 示例用法（消费 jikuai `synthesize` 如果落地）
- 多步管道组装：用户可串联多个块，预览中间结果（极快管道范式的 Web 可视化）
- 工作台历史：localStorage 存最近 20 条需求 + 组码结果，方便复用
- 若 jikuai `synthesize` 落地：删除 `_示例值表`（backlog 清债）

### 持续项（贯穿 Q4）

- 上游兼容性跟踪：四门语言每次 main 推送后 quye CI 自动验证
- 门禁标准逐步收紧：命中率阈值从 60% 提到 70%（块库补齐后）
- 无障碍审查：至少达成 WCAG 2.1 AA 级（键盘导航、屏幕阅读器、对比度）
- 性能预算：首屏 LCP < 2s（排除 Pyodide 加载）、zip 冷加载 < 5s（4G 网络）

### M4：CI 自动化 + 上游锁定（已交付）
- `.github/workflows/pages.yml`：产物自检硬门禁 + 命中率软门禁（`continue-on-error`，红牌只告警不阻塞）+ 每日定时；构建或自检失败 → deploy 跳过 → 旧站保留。
- `.github/workflows/upstream-drift.yml`：每日拉四门语言远端 HEAD，构建/自检失败自动开 issue（`上游漂移` 标签去重）。
- `建站.py`：`浅克隆()` 记录实际消费的 commit hash，`出/版本.json` 新增 `构建快照` 字段（本地路径/缓存与远端 HEAD 分离，暴露漂移）。
- 命中率门禁阈值 60% → 80%（实测 83%）。

### M5：SEO + 内容扩展（已交付）
- SEO：每页 `<meta description>` + `canonical` + Open Graph；构建期生成 `sitemap.xml`（58 页）+ `robots.txt`；产物自检加 SEO 门禁（每页 description/canonical 非空 + sitemap 收录数匹配）。
- 学习区扩展至 **33 关**（段言 10 + 光明 9 + 极快 8 + 知行 6），在线可判 28/33（5 个知行关因上游 parser 报错标为只读展示，非本站问题）。
- 首页「每日一题」：按日期确定性选关。
- 学习进度导出/导入 JSON（白名单校验关卡键）。
- 文档区纯前端搜索（构建期出 `数据/文档搜索索引.json`，中文二字滑窗打分）。

### M6：块生态门户化（已交付）
- 块浏览器 `/块`：极快 105 块 × 6 领域，按领域/关键词筛选，点击看签名与描述、在浏览器里跑官方示例。

- 多步管道组装：候选块「加入管道」，逐步跑并展示每步中间结果（极快管道范式的 Web 可视化）。

## 六、风险与依赖

- **jikuai `synthesize`**：M6 选块增强 + 删 `_示例值表` 的前提。不落地则 M6 缩减为只做块浏览器 + 历史记录。
- **光明 L2 规范稳定性**：L1 白话体在 M3 就暴露了 parser 与示例不一致；L2 文言体如果也不稳定，L2 关卡推迟到规范冻结后。
- **无 CI 期间的上游漂移**：M4 之前仍靠手动 `python 建站.py` 抓破坏。建议你每次给四门语言推 main 后顺手在 quye 目录跑一次构建。
- **搜索引擎收录周期**：提交 sitemap 后 Google 需要 2–4 周爬取，M5 的 SEO 验收不适合卡严格日期。
