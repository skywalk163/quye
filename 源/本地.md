# 本地开发

想把中文编程装到自己机器上？下面是四门语言的安装、命令行与编辑器配置。四门语言都在 GitCode 与 GitHub 双端同步，选就近的克隆。

## 极快 JiKuai

极简极速，主打「AI 而不依赖大模型」的块生态。

```bash
pip install -e .
jk 跑 你好.jk
```

- 三通道：CLI（`jk`）、LSP（编辑器智能提示）、Web 演示。
- 想写自己的块？看仓库 `docs/块生态.md`（怎么写、怎么发布）与 `docs/贡献指南.md`（贡献流程）。
- **安全提醒**：极快的 pybridge **不是沙箱**。`DENY_LIST` 只是黑名单，`importlib` 可以绕过（仓库 `docs/安全边界.md` 与 ADR-21 有明确声明）。别在本地跑来源不明的 `.jk` 文件。

## 段言 Duan

自举 + LLVM 后端，工具链在四门语言里最完整。

```bash
pip install duan
duan run 你好.duan
```

- 命令行：`duan run` / `compile` / `check` / `pkg` / `ai`。
- 编辑器配置看仓库 `docs/IDE配置指南.md`——四门语言里唯一一份专门的 IDE 文档。
- 内置 LSP 与 DAP，VS Code 里可以直接断点调试。

## 光明 Light

五层语法，从 L1 白话体一路到 L2 文言体。

```bash
pip install -e .
light 运行 你好.light
```

- 命令行工具、调试器、LSP、AI Copilot 都在仓库 `docs/tools.md`。
- 语法规范：`docs/L1_白话体语法规范_v4.0.md`（白话体）、`docs/L2_文言体语法规范_v4.0.md`（文言体）。
- 网站的学习区收了 L1 白话体前 9 课，可以先在线练完再装到本地。

## 知行 Zhixing

函数式 + 宏 + 同像性，管道语法是它的招牌。

```bash
git clone https://gitcode.com/skywalk163/zhixing
cd zhixing
python app.py
```

- `python app.py` 起本地 Playground 服务。
- 教程在仓库 `docs/tutorial.md`；从 Python 过来的看 `docs/py_to_yan_quickstart.md`。
- IDE 插件还在路线图上，暂时用 `editors/` 目录下的基础配置。

## 关于浏览器版与本地版的差别

网站上跑的是 Pyodide（CPython 编译到 WebAssembly），有几件事在浏览器里做不到：

- 网络请求、进程、线程、C FFI
- 包管理器的安装动作（抓取源码要 git 与网络）
- LLVM / ANTLR 后端与原生编译

这些能力都要装到本地才能用。浏览器版的定位是「零安装先试试」，认真写项目还是装本地。
