# 极快 JiKuai

> 极简 · 极速 · 极中国

一门为中国开发者量身定制的中文编程语言。

## 设计理念

- **双字关键词** — 无空格分词，句号结语句
- **管道式数据流** — 逗号管道串联操作：`列1 2 3 4 5，皆乘2，归加0。`
- **元数驱动解析** — 动词声明参数个数，免括号调用
- **中国特色内置** — 人民币类型、农历日期、中文正则、成语断言

## 代表示例

```jikuai
列1 2 3 4 5，皆乘2，只大于6，归加0。
-- 结果：18
```

```jikuai
定义王价格=￥99.90。
定义赵总价=王价格乘3。
打印赵总价。          -- ￥299.70
```

## 独有能力：AI 选块组码

用自然中文描述需求，启发式检索从 100+ 个代码块中选出最匹配的，组合成可运行代码——不需要大模型。
