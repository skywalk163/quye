# 知行 Zhixing

> 函数式 · 宏系统 · 同像性

一门基于 Python 实现的中文编程语言，支持 lambda、高阶函数、宏与同像性。

## 设计理念

- **同像性** — 代码即数据，支持元编程
- **宏系统** — 强大的宏定义和展开
- **函数式** — lambda、柯里化、高阶函数
- **管道操作** — 优雅的数据处理流程

## 代表示例

```zhixing
定平方=函x乘x x。
平方 5。        -- 结果: 25

列1 2 3 4 5，皆乘2。    -- 结果: [2, 4, 6, 8, 10]

定fact=函n：
  若n等1则1否则n乘fact $(n-1)。
。
fact 5。        -- 结果: 120
```
