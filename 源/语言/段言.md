# 段言 Duan

> 自举 · LLVM · AI Copilot

一门支持自举编译和 LLVM 原生编译的中文编程语言，兼顾教学与商用。

## 设计理念

- **自举编译器** — 段言编译器由段言自身编写
- **双后端** — Python 解释执行 + LLVM 原生编译
- **HM 全局类型推断** — 无需手动标注类型
- **AI Copilot SFT** — 支持微调的代码补全模型

## 代表示例

```duan
设 阶乘 为 函数(数)：
    如果 数 小于等于 1：
        返回 1
    否则：
        返回 数 乘以 阶乘(数 减去 1)

打印(阶乘(10))
```
